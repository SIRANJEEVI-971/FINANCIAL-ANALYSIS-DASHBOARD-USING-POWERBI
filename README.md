# 📊 Financial Analysis Dashboard using Power BI

## 📌 Project Overview
This project presents an interactive Power BI dashboard designed to analyze financial and sales performance across regions, products, and time periods. It enables data-driven decision-making through dynamic visualizations and KPI tracking.

---

## 🎯 Key Objectives
- Analyze total revenue and transaction trends  
- Compare performance across regions and countries  
- Identify top-performing stores and products  
- Track monthly and quarterly growth  

---

## 📈 Key Metrics
- Total Revenue: 127.41M  
- Average Revenue: 39.04K  
- Total Transactions: 3K  
- Total Countries: 3K  

---

## 🛠️ Tools & Technologies
- Power BI  
- Microsoft Excel  
- Data Modeling  
- DAX  

---

## 📊 Dashboard Features
- Interactive filters (Year, Quarter, Store)  
- Region-wise revenue analysis  
- Country-level performance tracking  
- Product performance insights  
- Monthly & quarterly trends  
- Sales representative performance
